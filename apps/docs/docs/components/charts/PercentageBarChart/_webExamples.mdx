## Basics

PercentageBarChart renders stacked bars whose segments always sum to 100% at each group index. Pass a `series` array where each item has `id`, `data` (array of numbers), and optional `label` and `color`. Values are normalized per group so any set of non-negative numbers can be used.

```jsx live
<PercentageBarChart
  height={24}
  series={[
    { id: 'confirmed', data: [93], label: 'Confirmed', color: 'var(--color-fgPositive)' },
    { id: 'review', data: [7], label: 'Need review', color: 'var(--color-fgCaution)' },
  ]}
  width={400}
/>
```

## Legend, axes, and multiple groups

Use `legend` and `legendPosition` for the built-in legend. Axes, `layout`, stacked segments, and category labels follow the same patterns as [BarChart](/components/charts/BarChart/). Here the value axis is always **0–100%** by default, and each group’s segments are normalized to a full bar.

### Single group with legend

```jsx live
<PercentageBarChart
  borderRadius={3}
  height={24}
  legend
  legendPosition="bottom"
  series={[
    { id: 'buy', data: [76], label: 'Bought', color: 'var(--color-fgPositive)' },
    { id: 'sell', data: [24], label: 'Sold', color: 'var(--color-fgNegative)' },
  ]}
  width={400}
/>
```

### Multiple groups with axes and legend

```jsx live
<PercentageBarChart
  legend
  showXAxis
  showYAxis
  borderRadius={6}
  height={200}
  series={[
    { id: 'btc', data: [55, 40], label: 'BTC', color: 'var(--color-fgWarning)' },
    { id: 'eth', data: [30, 45], label: 'ETH', color: 'var(--color-accentBoldPurple)' },
    { id: 'other', data: [15, 15], label: 'Other', color: 'var(--color-fgMuted)' },
  ]}
  stackGap={4}
  width={400}
  yAxis={{ data: ['Q1', 'Q2'], position: 'left', categoryPadding: 0.1 }}
/>
```
